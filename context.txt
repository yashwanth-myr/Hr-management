# Project Management System - Context Documentation

## Application Overview

This is a Next.js-based project management system for Tericsoft that includes:

- **Employee Management**: Create, edit, view employees with multiple department assignments
- **Department Management**: Manage departments and team leads
- **Project Management**: Create projects, manage team members, track progress
- **Project Allocations**: Monthly resource allocation and planning
- **Performance Forms**: Score-based evaluation system
- **Reports**: Performance tracking and analytics

## Technology Stack

- **Frontend**: Next.js 12, React 17, Tailwind CSS
- **Backend**: Next.js API routes
- **Database**: PostgreSQL (Remote server: 15.207.229.182:1803)
- **UI Components**: Custom component library with shadcn-style design
- **Icons**: React Icons (Feather Icons)
- **Notifications**: React Toastify

## Database Schema Overview

### Core Tables

1. **employees** - Employee information
   - id (TEXT, Primary Key)
   - name, email, phone_number, designation, job_role
   - department_id (Legacy, for backward compatibility)

2. **departments** - Department information
   - id (TEXT, Primary Key)  
   - name, team_lead_id (Legacy)

3. **employee_departments** - Many-to-many relationship (NEW)
   - employee_id, department_id
   - Allows employees to belong to multiple departments

4. **projects** - Project information
   - id (TEXT, Primary Key)
   - name, start_month, start_year, status, project_manager_id

5. **project_members** - Project team members
   - project_id, employee_id

6. **project_allocations** - Monthly allocations
   - project_id, month, year, project_manager_id

### Supporting Tables
- department_team_leads, allocation_members, score_forms, form_questions, etc.

## Current Project Display Structure

The project listing uses a hierarchical view:

1. **Year Selection**: User selects a year (2025, 2024, etc.)
2. **Month Grouping**: Projects are grouped by their start month within that year
3. **Month Cards**: Each month shows as a card (e.g., "June 2025") with project count
4. **Project Details**: Clicking a month expands to show individual projects

**Example Display**:
```
2025 (4 projects)
├── June 2025 (2 projects)
│   ├── Project A (June 2025, 3 members)
│   └── Project B (June 2025, 1 member)
└── July 2025 (2 projects)
    ├── Project C (July 2025, 0 members)
    └── Project D (July 2025, 2 members)
```

### Admin

### Project Manager
- Manage assigned projects

- View assigned projects
- Limited project access
- Cannot edit projects or teams
